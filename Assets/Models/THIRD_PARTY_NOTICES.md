# Third-Party Model Notices

This directory contains local test assets copied from the Khronos Group
glTF-Sample-Assets repository:

https://github.com/KhronosGroup/glTF-Sample-Assets

The upstream repository states that model license summaries are shown in the
generated model lists, and that each model directory's README contains the
detailed license information. The notices below summarize the upstream README
entries for the sample assets currently copied into this repository.

Unless otherwise noted, local copies are used for renderer and asset-loading
tests and have only been reorganized into this project's asset tree.
