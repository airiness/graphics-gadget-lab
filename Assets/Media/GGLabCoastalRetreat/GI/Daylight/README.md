# Pre-GI Coastal Daylight baseline

[baseline.json](baseline.json) indexes the original captures, SHA-256 identities
and repeat results for four views on DX12 and Vulkan. Captures use RTX 3060,
Develop with `GGLAB_ENABLE_PIX=0`, standard native validation, 1280x800 Native and
fixed EV100 15. These are pre-GI regression images, not GI quality or timing results.
See [GI qualification inputs](../../../../../Tests/Verification/GlobalIllumination/README.md)
for the input lock and validation command.
