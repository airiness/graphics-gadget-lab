# GI reference lighting verification

The GI Reference Lab measures scene-referred diffuse irradiance using environment
misses and Sun-lit secondary surfaces. Fixtures follow the frozen specification
identified by `Inputs.json`.

## Inputs and observations

Fixture values 0/1/2 select F1 sphere, F1 plane and F2. Values 3/4 select
F3/F4; 5/6 are independent sun transport and off-camera shadow-blocker contracts;
7 is a sphere for published-environment contracts. Lighting-contract parameters
do not change frozen F1-F4 lighting. Every configuration change uses RestartSession.

The sun contract has a horizontal receiver at Y=0 and a vertical secondary plane
at Z=2, X [-2,2], Y [0,4]. Photon direction is normalized (0,-1,1), with 10,000 lux,
neutral or red secondary albedo, receiver albedo variants and optional atmosphere.
A roof above the locked camera view blocks all secondary sunlight.

Synthetic environments are original procedural assets generated by:

~~~powershell
python Tests/Verification/GlobalIllumination/GenerateReferenceEnvironments.py
python Tests/Verification/GlobalIllumination/GenerateReferenceEnvironments.py --check
~~~

They pass through the ordinary HDR import, environment bake and atomic publication.
DirectXTex decodes RGBE bin centres; the encoded constant decodes to 1.00390625,
which the direct-input contract matches exactly. F1 keeps its frozen radiance 1.
The directional source approximates RGB = 1 + 0.5 * direction.xyz. Its independent
unoccluded irradiance is pi * (1 + normal_in_environment_space / 3), before
intensity. RGBE quantization and filtering are included in the reported error.

The default published-environment filter selects the actual LOD for a 32-texel
face. Mip zero is an explicit comparison signal. Physical Sky uses the existing
published radiance environment without the solar disc. Increasing samples cannot
remove a difference between these filtered signals.

SunIrradiance RGB and EnvironmentIrradiance RGB sum to Irradiance RGB. Their alpha
channels record whether atmosphere attenuation was bound and the selected LOD
(-1 for direct constant input). Identity alpha distinguishes centre-ray primary
matches (1) from bounded silhouette fallback (2). The latter searches a per-axis
1/128-pixel envelope with a 2-micrometre minimum, requires matching face/depth,
and never changes secondary hit/miss semantics. Invalid receivers still fail.

Observations resume fixed-seed sampling across bounded GPU submissions. Sums,
counts and RNG state advance together only on Submitted; failed/discarded work
never contributes. Input changes start a new observation. Batch partitioning must
preserve the sample sequence and complete output arrays.

`gi_reference.samples` sets the observation total; `gi_reference.batch_samples`
limits samples per submission. Runtime also caps pixel count times batch samples.
Limits are defined by [GIReference.h](../../../Sources/GGLabRuntime/Public/GGLabRuntime/Graphics/Pipeline/GIReference.h)
and input validation. This bounds sampling work, not execution time.

`after-ready` waits for GPU completion through the `gi-reference` readiness gate.
Completed means calculated, not converged. Accumulation does not reuse TAA or
other observations.

## Independent checks and masks

ValidateGIReferenceLighting.py computes the sun contract's rectangle form factor
analytically and atmosphere optical depth with independent float64 quadrature.
It checks final receiver E, not only secondary surface radiance. Sun intensity,
secondary material and receiver material change independently.

The frozen F4 opening does not directly illuminate its coloured side walls.
A beam entering with |X| <= 1 and Y <= 3 reaches the floor before X can reach
either coloured wall (the largest X is 1 + 0.2 * 3 = 1.6 < 2). Stopping at the
first secondary hit therefore produces neutral solar transport. The floor and
right jamb reflect sun. The CPU oracle includes the complete opening thickness,
sunlit floor strip and jamb, with separate sky integration. The independent
red-secondary contract checks colour transport.

F3 checks every interior receiver, including seams, for zero irradiance and
zero sky misses, and retains an exterior roof control. F4 preserves floor,
back-wall and separate red/green-adjacent neutral-floor masks. Selectors intersect
snapshot instance/primitive identities with frozen world intervals. Every required
mask must be nonempty and has a retained PNG overlay.

## Gates and reproduction

Compare unexposed linear RGB E and its Rec.709 luminance. CPU-oracle agreement,
independent seeds and sample doubling each require less than 1% change for E
and for the sun/environment components separately, with
a 1e-6 absolute normalization floor for dark values. Sealed interiors remain
exactly black. Cross-RHI checks compare identical mask membership and ROI means;
complex per-pixel paths need not be bit-identical. Filter bias is reported
separately, including per-pixel RGB RMSE and maximum error, luminance NRMSE, and
95th-percentile/maximum luminance differences so ROI averaging cannot hide it.
SamplingConverged alone does not qualify an ROI for DDGI comparison: it remains
ReferenceUnconverged until depth convergence is also established.

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tests/Verification/RunVerification.ps1 -Suite gi-reference-contracts -Python <python-with-numpy-and-jsonschema>
powershell -NoProfile -ExecutionPolicy Bypass -File Tests/Verification/RunVerification.ps1 -Suite gi-reference -Configuration Develop -Rhi dx12,vulkan -Python <python-with-numpy-and-jsonschema>
~~~

The GPU suite preserves actual World Lighting generations, environment inputs,
LOD, seed, sample count, masks and graph evidence. It checks identical-seed estimates
across batch partitions and observations larger than a single batch. Develop also
checks GI-off Coastal captures against pinned pixels and effective inputs, with no
GI or ray-scene graph work. Native validation, resource/bundle/graph schemas and
clean session shutdown are required.

For same-adapter controls from a known source revision, invoke
`TestGIReference.ps1 -GIOffBaselineDirectory <directory>` with `dx12` and `vulkan`
subdirectories containing the control captures. The receipt records the selected
directory and whether the pinned baseline was used. Pixel and input gates apply
to either baseline.

## Automatic ROI qualification

`TestGIReferenceConvergence.ps1` runs fixed 640x400 F1 plane, F2/F3 floor and
frozen F4 floor/back views. F4 retains separate red/green-adjacent floor masks.
At each depth it observes both seeds 61051/61052 at N and 2N. Both seed comparisons
and both sample-doubling comparisons must pass for RGB and Rec.709 luminance of
E, Sun and environment separately. The strict relative limit is 0.01, with
denominator `max(abs(reference), 1e-6)`, matching the existing lighting gates. The
higher sample/depth result is the reference for doubling. All receivers and any-bounce invalid paths
are checked before computing ROI statistics.

Depth comparisons use 8/16/32/64/128/256, with sampling qualified on both sides at
the same N, seeds, camera and masks. If more samples are needed, the lower depth
is observed again at that common N. A certificate selects the higher depth and
larger sample count; it is scoped to the recorded ROI and inputs. Limits produce
`ReferenceUnconverged`, never permission to judge DDGI against an unconverged ROI.
F1-F3 default to N=64 and F4 to N=4096; initial counts, depth/sample ceilings and
execution budgets are explicit run settings. Numerical settings belong to the recipe;
execution budgets are retained per attempt and may be increased on resume. The first candidate is 2N.

Runtime reduces samples per sweep before spatial tiling. At D64/128/256 even a
single whole-image sample exceeds the conservative query budget, so tiles span
submissions. The first tile initializes all pending pixels. Later tiles declare
ReadWrite preservation. Submitted advances the tile cursor; only a complete sweep
publishes all six sum/compensation/RNG pairs. Completion gates the next tile and
capture readiness. Partial sweeps resolve the previous complete estimate.
The optional `gi_reference.tile_pixels` changes execution partitioning only.

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tests/Verification/RunVerification.ps1 -Suite gi-reference-tiling -Configuration Develop -Rhi dx12,vulkan -Python <python-with-numpy-and-jsonschema>
powershell -NoProfile -ExecutionPolicy Bypass -File Tests/Verification/TestGIReferenceConvergence.ps1 -RunDirectory Build/Validation/GIReferenceConvergence/MyRun -Python <python-with-numpy-and-jsonschema>
# Resume explicitly with exactly the same numerical recipe and source/binaries.
powershell -NoProfile -ExecutionPolicy Bypass -File Tests/Verification/TestGIReferenceConvergence.ps1 -RunDirectory Build/Validation/GIReferenceConvergence/MyRun -Resume -Python <python-with-numpy-and-jsonschema>
~~~

New runs refuse an existing directory. Checkpoints contain only validated completed
captures and SHA-256 receipts; incomplete attempts are preserved under distinct retry
directories. Resume audits source/compiler/product binary hashes, configuration,
device/driver, effective lighting, camera, extent and masks. World Lighting generation
values are recorded per capture; safe Lab restarts need not share generation numbers.
Per-pass compiled shader identities remain unavailable; the recipe hashes shader
sources and compiler binaries explicitly instead of inventing artifact identities.
N remains an observation identity, so changing N restarts Runtime accumulation.

`MaximumObservations` limits total cached observations; `MaximumSeconds` limits each
attempt between observations (an in-flight observation has `TimeoutSeconds`). An
optional `CancellationFile` requests a clean stop at an observation boundary. Reports
distinguish Running, Cancelled, Failed, ReferenceUnconverged and ReferenceConverged.
Only immutable completed captures are reusable. Both-RHI runs also compare common
qualified candidates per ROI with the declared 1% rule and identical masks; differing
selected depth/sample candidates are explicitly unavailable for that comparison.
Runtime Completed remains calculation progress, not numerical certification.
